## 📌 Proje Hakkında

Bu repository, İnönü Üniversitesi Bilgisayar Mühendisliği Bölümü
**Veri Yapıları (Data Structures)** dersi kapsamında oluşturulmuştur.

Ders süresince işlenen konulara ait kod örnekleri, algoritmalar
ve uygulamalar düzenli olarak bu repository içerisinde paylaşılacaktır.

Projenin temel amacı, veri yapılarının çalışma mantığını anlamak,
algoritmik düşünme becerisini geliştirmek ve teorik bilgileri
uygulamalı örneklerle pekiştirmektir.

## 🧠 Algoritma Analizi

Veri yapıları ve algoritmalar değerlendirilirken
zaman ve alan karmaşıklıkları dikkate alınacaktır.

### Big-O Notation

| Karmaşıklık | Açıklama |
|-------------|----------|
| O(1) | Sabit zaman |
| O(log n) | Logaritmik zaman |
| O(n) | Doğrusal zaman |
| O(n log n) | Doğrusal-logaritmik zaman |
| O(n²) | Karesel zaman |
| O(2ⁿ) | Üstel zaman |

Algoritmaların performansları farklı veri boyutları
üzerinden incelenerek karşılaştırılacaktır.
